Notas para a reunião

Decisões tomadas no wireframe

  • Mobile-first, mas com Desktop responsivo (não app nativo) — mantém escopo viável para 3 pessoas
  • Cadastro de tutor é invite-based pela clínica, não self-service público
  • Timeline única alimentada pela mesma tabela de eventos clínicos usada pelo front do veterinário (reutilização máxima)
  • Prescrição em MVP é PDF estruturado — assinatura ICP-Brasil fica para pós-challenge
  • Bottom nav com 4 itens (Home, Agenda, Receitas, Perfil) — regra de ouro em mobile
  • LGPD tratada como seção própria, não como checkbox escondido

Perguntas em aberto para o time

  • Lembretes via WhatsApp entram no MVP? (custo Meta + dev adicional)
  • Tutor pode agendar direto pelo portal ou só pede retorno? (fluxo de agendamento é trabalhoso)
  • Chat tutor ↔ clínica entra no MVP ou é fase 2? (risco de virar teleconsulta clandestina → problema CFMV)
  • Upload de documentos pelo tutor (foto de exame antigo, etc) — precisa para MVP?
  • Stack de front: React + Tailwind? Next.js? Vite? Definir antes da próxima sprint
  • Quem desenha o Figma hi-fi a partir deste lo-fi?
